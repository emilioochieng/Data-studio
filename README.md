# Data Dashboard (Streamlit)

Upload three CSV files, clean and merge them, then explore the result.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy free
1. Push this folder to GitHub.
2. Go to share.streamlit.io, connect the repo and choose `app.py`.
3. Copy the app link into the "Open dashboard" button on the website.

## Files
- `app.py`: the dashboard
- `clean_merge.py`: cleaning and merging functions (also usable from the command line)
- `requirements.txt`: packages
